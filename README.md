# Графический редактор на Fabric.js

Веб-приложение для создания и редактирования графических композиций с помощью библиотеки Fabric.js.

## Возможности

### Фоновые фигуры
- **Круг** - создание круглых фоновых элементов
- **Квадрат** - создание прямоугольных фоновых элементов  
- **Треугольник** - создание треугольных фоновых элементов
- **Настройка цвета** - выбор любого цвета для фоновых фигур

### Иконки
- **Звезда** (★) - добавление звездочек
- **Зонтик** (☂) - добавление зонтиков
- **Треугольник** (▲) - добавление треугольных иконок
- **Настройка цвета** - выбор любого цвета для иконок

### Управление объектами
- **Выделение** - клик по объекту для выбора
- **Перемещение** - перетаскивание выбранного объекта
- **Изменение размера** - потягивание за углы объекта
- **Поворот** - вращение объекта за специальный маркер
- **Множественное выделение** - Ctrl + клик для выбора нескольких объектов

### Горячие клавиши
- **Delete / Backspace** - удалить выбранный объект
- **Ctrl + D** - дублировать выбранный объект

### Экспорт
- **PNG** - экспорт в растровый формат
- **SVG** - экспорт в векторный формат
- **Масштабирование** - настройка масштаба от 0.5x до 3x для экспорта

### Масштабирование холста
- **Слайдер масштаба** - изменение размера отображения от 0.5x до 3x
- **Адаптивный холст** - автоматическое подстраивание под размер экрана

2. Откройте `index.html` в браузере
3. Приложение готово к использованию

- **Fabric.js 5.3.0** - подключается через CDN
- Интернет-соединение требуется только для загрузки библиотеки

## Использование

### Создание фоновых фигур
1. Выберите цвет в разделе "Цвет фигур фона"
2. Нажмите на нужную фигуру (●■▲) в разделе "ФОН"
3. Фигура появится в центре холста

### Добавление иконок
1. Выберите цвет в разделе "Цвет иконок"
2. Нажмите на нужную иконку (★☂▲) в разделе "ИКОНКИ"
3. Иконка появится в случайном месте холста

### Редактирование объектов
1. **Выделение**: кликните по объекту
2. **Перемещение**: перетащите объект в нужное место
3. **Изменение размера**: потяните за угловые маркеры
4. **Поворот**: потяните за круглый маркер над объектом
5. **Изменение цвета**: выберите объект и поменяйте цвет в соответствующем разделе

### Экспорт результата
1. Настройте масштаб экспорта слайдером
2. Нажмите кнопку "PNG" или "SVG"
3. Файл автоматически скачается
